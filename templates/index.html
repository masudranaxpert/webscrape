API Reference

POST /fetch
Main stealth scraping pipeline

Primary endpoint for fetching content. Automatically routes through the fast-path or executes Cloudflare bypass via the persistent browser pool.

Request Parameters (JSON Body)

Field Requirement Type Default Description
url Required string — Target URL to fetch (e.g. https://example.com/protected-page).
method Optional string "GET" HTTP Method (GET, POST, PUT, DELETE, PATCH).
headers Optional object {} Custom request headers merged into preset browser header order.
body Optional string | null null Raw request payload for POST/PUT requests.
user_agent Optional string | null null (auto) Custom User-Agent header string. When null, uses preset's authentic UA.
preset Optional string "chrome-latest-windows" Fingerprint profile (chrome-latest-windows, chrome-latest-linux, firefox-latest).
proxy Optional string | null null Proxy URL (e.g. http://proxy:8080 or socks5://127.0.0.1:1080).
force_browser Optional boolean false Set true to skip fast-path and force headless browser execution.
cf_wait Optional float 10.0 Maximum wait seconds for Turnstile settlement in browser.
cookie_ttl Optional integer 3600 Cookie cache retention duration in seconds.
inject_cookies Optional object {} Custom cookies to inject into this request before navigation.
cookie_allowlist Optional string[] | null null (auto) Allowed cookie names or glob/regex patterns (e.g. ["cf_*", "__cf*", "PHPSESSID", "token_*"]). Filters out junk/tracking cookies.
cookie_limit Optional integer 35 Maximum number of cookies allowed in request header before truncating oldest to prevent HTTP 400 buffer overflow.
selector Optional string | null null CSS selector to parse and extract from HTML on the server.
selector_all Optional boolean false Return all matching elements (true) or first match (false).
selector_attr Optional string "text" Attribute to extract: "text", "html", "href", "src", etc.

The API includes a high-performance C-based HTML parser (selectolax Lexbor) on the backend. Instead of downloading and parsing megabytes of HTML in your client code, you can pass CSS selectors directly to receive cleanly extracted text or attributes.

  • selector: Any standard CSS selector (e.g. "h1", "table.torrent-table > tbody > tr", "a.download-btn").
  • selector_all: Set to true to return an array of all matches; set false to return the first matching element.
  • selector_attr: Choose "text" (default, trimmed innerText), "html" (outerHTML), or any HTML attribute name like "href", "src", "data-id".
Example: Extract all download links with CSS selectors 
{
  "url": "https://example.com/items",
  "selector": "a.download-btn",
  "selector_all": true,
  "selector_attr": "href"
}

The service includes a built-in Domain-Aware LRU In-Memory Cookie Store with Pattern Allowlist Filtering & Header Overflow Guards. When a Cloudflare Turnstile challenge is solved, clearance tokens and sessions are stored automatically. Subsequent requests reuse these cookies to hit the fast-path (300ms) without opening a browser.

  • cookie_allowlist: Array of allowed cookie names or glob/regex wildcard patterns (e.g. ["cf_*", "__cf*", "*session*", "movielinkbd_vote_*", "PHPSESSID"]). Only matching cookies are stored and sent; ephemeral post-view counters, Google Analytics (_ga), and tracking noise are automatically pruned.
  • cookie_limit: Upper bound on the number of cookies sent in outbound request headers (default 35, 3.5 KB max). If crawling many subpages accumulates excess cookies, the engine safely truncates older non-essential cookies and logs an informative notification, preventing OpenResty/Nginx 400 Request Header Or Cookie Too Large errors.
  • inject_cookies: Inject custom session cookies (e.g. logged-in user tokens) into both the HTTP engine and the browser context before navigation. Injected cookies always bypass the allowlist filter and are preserved.
  • cookie_ttl: Controls how many seconds harvested cookies stay valid in memory (default 3600 = 1 hour).
  • LRU Eviction: Stores up to 10 distinct domains concurrently in memory. Least recently used domain entries are gracefully evicted when capacity is reached.
Example: Cookie Allowlist, Limits & Custom Injection 
{
  "url": "https://example.com/protected-series",
  "cookie_allowlist": [
    "cf_*",
    "__cf*",
    "*session*",
    "PHPSESSID"
  ],
  "cookie_limit": 25,
  "inject_cookies": {
    "session_auth": "d7cacaacbab36dcb309df17425793931",
    "user_id": "48291"
  }
}

The system manages a persistent single Chromium process started once at application boot. Incoming requests acquire a worker tab through a semaphore pool (configurable via MAX_TABS in .env) and automatically clean up tabs and isolated browser contexts upon completion.

  • force_browser: Set to true to skip the HTTP fast-path and drive Chrome directly. Use this for complex Single Page Apps (SPA) that require client-side JavaScript rendering.
  • cf_wait: Maximum duration in seconds to wait for Cloudflare Turnstile to solve and redirect (default 10.0s).
  • Dynamic Redirect Cache: When an origin domain redirects to a separate domain post-challenge (e.g. .com → .net), the API caches the destination so subsequent requests hit the final URL directly on the fast-path.
Example: Forcing browser with custom challenge timeout 
{
  "url": "https://example.com/dynamic-spa",
  "force_browser": true,
  "cf_wait": 15.0
}

Fine-tune the wire-level network behavior, fingerprint profiles, proxy routing, and User-Agent headers.

  • user_agent: Pass a custom User-Agent string to override the preset's default. If omitted, the authentic preset User-Agent is sent.
  • preset: Select from bundled browser fingerprint profiles: "chrome-latest-windows", "chrome-latest-linux", "chrome-latest-macos", "firefox-latest", "safari-latest".
  • proxy: Route requests through HTTP, HTTPS, or SOCKS5 proxies. Browser tabs run in dedicated, isolated browser contexts to prevent proxy leakage.
  • http_version: Force protocol version ("h1", "h2", "h3") or leave as null for auto-negotiation via ALPN.
Example: Custom User-Agent and SOCKS5 Proxy 
{
  "url": "https://example.com/api/data",
  "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36",
  "proxy": "socks5://127.0.0.1:1080",
  "preset": "chrome-latest-windows",
  "timeout": 45
}

Usage Examples

Python (httpx / requests) 
import httpx

# Send stealth request
response = httpx.post(
    "http://127.0.0.1:8000/fetch",
    json={
        "url": "https://example.com/protected-page",
        "selector": "title",
        "cf_wait": 10.0
    },
    timeout=30.0
)

data = response.json()
print("Status Code:", data["status_code"])
print("Engine Used:", data["meta"]["via"])
print("Cache Hit:  ", data["meta"]["cache_hit"])
print("Extracted:  ", data["extracted"])
