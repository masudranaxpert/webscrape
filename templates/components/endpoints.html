API Reference

POST /fetch

Primary endpoint for fetching content. Automatically routes through the fast-path or executes Cloudflare bypass via the persistent browser pool.

Authentication & Request Headers

Header Requirement Type Description
X-API-Key Required string Secret API key configured in .env (e.g. anti_secret_key_123). 100% required for direct API endpoints (/fetch, /solve-turnstile, /cookies). Missing or invalid keys return 401 Unauthorized.
Authorization Optional string Bearer token alternative: Bearer <your_api_key>.
Content-Type Required string Must be set to application/json.

Request Parameters (JSON Body)

Field Requirement Type Default Description
url Required string — Target URL to fetch (e.g. https://example.com/protected-page).
method Optional string "GET" HTTP Method (GET, POST, PUT, DELETE, PATCH).
headers Optional object {} Custom request headers merged into preset browser header order.
body Optional string | null null Raw request payload for POST/PUT requests.
user_agent Optional string | null null (auto) Custom User-Agent header string. When null, uses preset's authentic UA.
preset Optional string "chrome-latest-windows" Fingerprint profile (chrome-latest-windows, chrome-latest-linux, firefox-latest).
proxy Optional string | null null Egress proxy: http://, https://, socks5:// or socks5h://, credentials allowed (socks5://user:pass@host:port). Omit to use direct or server WARP egress, or send "direct" to bypass it. Invalid values return 422. See Proxy guide.
force_browser Optional boolean false Set true to skip fast-path and force headless browser execution.
force_http Optional boolean false Set true for HTTP only: never escalate to the browser; the raw response (even 403 or a challenge page) is returned as-is. Cannot be combined with force_browser.
cf_wait Optional float 25.0 Maximum wait seconds for Turnstile settlement in browser (early-exits immediately upon resolution).
session_id Optional string | null null Isolated session identifier (e.g. task-dl-1). Prevents cookie/session collisions between concurrent multi-step scraping tasks while sharing root-domain Cloudflare clearance.
wait_for_selector Optional string | null null CSS selector that must exist in live DOM before returning. Forces browser escalation if fast-path HTML lacks it (useful for client-rendered dynamic buttons).
click_selector Optional string | null null CSS selector to click once the page/Turnstile is resolved. Waits while the element is disabled, then reports what the click did: every navigation hop in redirect_chain (url, status, location) and the file's address if it started a download (the file itself is never fetched). Implies force_browser.
cookie_ttl Optional integer 86400 Cookie cache retention duration in seconds (default 24 hours).
inject_cookies Optional object {} Custom cookies to inject into this request before navigation.
cookie_allowlist Optional string[] | null null (auto) Allowed cookie names or glob/regex patterns (e.g. ["cf_*", "__cf*", "PHPSESSID", "token_*"]). Filters out junk/tracking cookies.
cookie_limit Optional integer 35 Maximum number of cookies allowed in request header before truncating oldest to prevent HTTP 400 buffer overflow.
selector Optional string | null null CSS selector to parse and extract from HTML on the server.
selector_all Optional boolean false Return all matching elements (true) or first match (false).
selector_attr Optional string "text" Attribute to extract: "text", "html", "href", "src", etc.

POST /solve-turnstile

Directly solves a Cloudflare Turnstile challenge and obtains a single-use token from the target widget's sitekey and origin siteurl. Uses route interception to avoid downloading third-party page assets.

Request Parameters (JSON Body)

Field Requirement Type Default Description
sitekey Required string — Turnstile widget sitekey (0x...). Strictly validated against ^[A-Za-z0-9_-]{1,128}$.
siteurl Required string — Full URL of the origin domain the sitekey is authorized for (e.g. https://example.com/protected-form).
timeout Optional integer 30 Max seconds to wait for the browser worker to solve the widget (5 to 120s). Returns 504 on timeout.
proxy Optional string | null null Egress proxy for the solve session. Omit for direct/WARP connection.

Response Schema

JSON Response 
{
  "solved": true,
  "token": "0.m9V_sample_turnstile_response_token_...",
  "elapsed": 2.45,
  "siteurl": "https://example.com/protected-form",
  "proxy": null
}
